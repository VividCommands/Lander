System Requirements

What You Need

Minimum

  • Windows 10 or Windows 11
  • Dual-core 64-bit processor
  • 4 GB RAM
  • 200 MB free disk space
  • Internet for download and first activation

Recommended

  • Windows 10 or Windows 11, up to date
  • Intel Core i5 / AMD Ryzen 5 or similar
  • 8 GB RAM
  • SSD system drive
  • Stable internet connection
Note: Lonware software runs on Windows PCs. Administrator access is needed when a tool applies system-level changes. Individual products may have additional setup steps.
Quick Start

Getting Started

01

Check Your Email

Download link and license key arrive at checkout email. Check spam folder if not received within 15 minutes.

02

Run as Administrator

Right-click and select Run as administrator. Required for PC optimization products to apply system-level changes.

03

Keep Your Security On

Download from your purchase link. If your security software flags a file, contact support before opening it.

04

Follow the Setup Guide

Every product ships with clear step-by-step documentation. Read fully before starting. No technical expertise required.

05

Restart Your PC

After applying optimizations, restart to ensure all changes take effect. Some settings only activate after a clean reboot.
