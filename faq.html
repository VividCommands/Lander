Choosing a product

Which Lonware tool should I start with?

+

Choose the problem you can actually feel. Use Optii for PC health checks, Windows cleanup, and controlled system optimization; PingR for game boosting and live latency monitoring; Macro.io for custom input routines; and Bloom Reducer for sensitivity and acceleration guidance. The Ultimate Bundle brings the core tools together.

Do I need to be a competitive player?

+

No. Lonware is for anyone who wants a more organized way to tune a gaming setup. Competitive players may care more about consistency, but the tools do not require tournament experience or advanced technical knowledge.

Can you promise a specific FPS or ping change?

+

No honest tool can promise the same number for every setup. Hardware, Windows condition, internet provider, distance from the game server, and your existing settings all matter. Lonware helps you address avoidable local issues; results are strongest when there is something meaningful to correct.

Using it responsibly

What should I do before changing PC settings?

+

Read the included instructions, close important work, and use the provided restore or reversal steps. PC configurations differ, so apply changes deliberately instead of treating every optional setting as mandatory.

Are macros allowed in every game?

+

Rules vary by game, platform, tournament, and macro behavior. Lonware cannot guarantee that every configuration is permitted everywhere. Check the rules for the game or event you are playing and use Macro.io only in ways those rules allow.

How do I stop or reverse a Lonware setup?

+

Close Macro.io to stop its active inputs. For optimization products, follow the restore instructions included with that product. If anything is unclear, pause before making more changes and ask in Discord with your Windows version and the step you reached.

Your setup

What systems can use Lonware?

+

Lonware software is made for Windows 10 and Windows 11 PCs. Macro.io supports keyboard input and compatible Xbox or PlayStation controllers on PC. Review the product page before purchasing if you use macOS, Linux, or a customized Windows build.

Will Macro.io recognize my controller?

+

Macro.io is designed for common Xbox and PlayStation-style controller layouts as well as keyboard input. Controller behavior can depend on its driver and connection method, so contact us before buying if you use an uncommon adapter or third-party controller.

Will the network tool work on Wi-Fi?

+

Yes, the guidance can be used with Wi-Fi or Ethernet. Ethernet is usually more consistent, and no local setting can remove congestion, weak signal, provider routing, or physical distance from a game server.

Purchase and access

Where is my download or key after checkout?

+

Payhip shows the product access after checkout and also sends it to the email used for the purchase. Check spam or promotions if the email is missing. If you still cannot find it, contact us in Discord with your receipt details, but do not post your key publicly.

Can I use one Macro.io key on multiple PCs?

+

Keys are intended for one customer and one authorized PC at a time. If you replace hardware or believe your key is attached incorrectly, contact support rather than sharing or purchasing around the activation system.

What does Lifetime mean for Macro.io?

+

Macro.io Lifetime removes recurring access payments for that product and includes future Macro.io updates while it remains supported. It does not automatically include separate Lonware products unless you purchased a bundle that lists them.
